# 悬浮标 Obsidian 插件

在笔记里选中一段文字，按一下命令发给已登录的 ChatGPT / Gemini，
**回答直接插在选区下面**。不需要 API key。

## 安装

零构建，两个文件拷过去就行：

1. 在库里建目录 `<你的库>/.obsidian/plugins/xuanfubiao/`
2. 把本目录下的 `main.js` 和 `manifest.json` 拷进去
3. Obsidian → 设置 → 第三方插件 → 刷新 → 启用「悬浮标」

然后在悬浮标的托盘菜单里打开 **「允许本机程序调用」**。
密钥会被自动读到（插件设置页会显示「已自动读到」），不用手填。

## 三个命令

在命令面板（`Ctrl+P`）里搜「悬浮标」：

- **问 AI（选中的内容）** —— 发给设置里选的默认目标
- **问 ChatGPT（选中的内容）**
- **问 Gemini（选中的内容）**

建议给最常用的那个绑一个快捷键。

## 设置

- **调用密钥** —— 留空即自动读取，一般不用动
- **默认发给** —— 「问 AI」用哪家
- **回答用引用块包起来** —— 默认开。插进来的是 AI 写的，和自己写的正文分开更清楚

## 几件得先知道的事

- **只能在桌面版用。** 它要连 `127.0.0.1`，而悬浮标是个 Windows 桌面程序。
- **要等几十秒**，期间可以继续写别的 —— 回答会插到**你按下命令时选区的末尾**，
  不是插到光标当前位置。等待期间光标早就跑别处去了，插在那儿会打断你。
- **一次只能跑一个**，第二个命令会排队。
- 那条问答会真实出现在你自己的 ChatGPT 对话历史里。
